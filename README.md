# Projeto Biblioteca

Projeto acadêmico desenvolvido para praticar consultas em **SQL** utilizando um cenário de biblioteca.

A consulta reúne informações de empréstimos, leitores e livros relacionados.

## Tecnologias

- PostgreSQL
- SQL
- pgAdmin

## Conceitos praticados

- Consulta de dados com `SELECT`
- Junção de tabelas com `JOIN`
- Uso de aliases para facilitar a leitura
- Ordenação de resultados com `ORDER BY`
- Relacionamento entre tabelas

## Arquivo

- `biblioteca.sql`: consulta os empréstimos e apresenta o nome do leitor, o título do livro e as datas do empréstimo e da devolução.

## Como executar

1. Abra o pgAdmin e conecte-se ao banco de dados que contém as tabelas `emprestimos`, `leitores` e `livros`.
2. Abra o Query Tool.
3. Execute o conteúdo do arquivo `biblioteca.sql`.

**Observação:** este arquivo contém a consulta SQL. As tabelas precisam existir previamente no banco de dados.

Projeto de estudo em desenvolvimento durante a graduação.
