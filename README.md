# Projeto Biblioteca

Projeto de estudo desenvolvido durante a faculdade para praticar SQL e PostgreSQL.

O banco representa uma biblioteca, com informações sobre leitores, livros e empréstimos.

## Tecnologias

- PostgreSQL
- SQL
- pgAdmin

## O que pratiquei

- Consultas com SELECT
- Relacionamento entre tabelas
- JOIN para reunir informações
- Organização de dados

## Arquivo

- `biblioteca.sql`: consulta os empréstimos e exibe os dados dos leitores e livros relacionados.

Projeto desenvolvido para praticar e continuar aprendendo sobre bancos de dados.
