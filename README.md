Projeto Biblioteca

Projeto de banco de dados desenvolvido durante meus estudos de Ciência da Computação, com foco em SQL e PostgreSQL.

Sobre o projeto

O projeto simula o funcionamento básico de uma biblioteca, utilizando tabelas para organizar informações de leitores, livros e empréstimos.

Tecnologias utilizadas
PostgreSQL
SQL
pgAdmin
Conceitos praticados
Criação de banco de dados
Criação de tabelas
Inserção de dados
Consultas SQL
Chaves primárias
Relacionamento entre tabelas
Organização de dados
Objetivo

Praticar os fundamentos de banco de dados e desenvolver experiência com SQL e PostgreSQL por meio de um projeto prático.

Projeto desenvolvido como parte dos meus estudos em Ciência da Computação.
